## 📌 О контексте и пользователях
[cite_start]Дашборд разработан для внутренней команды: менеджеров продукта, бренд-менеджеров, аналитиков и маркетологов[cite: 5]. [cite_start]Главная цель инструмента — видеть общую картину бизнеса и понимать, какие изменения произошли за последний месяц[cite: 15]. 

[cite_start]Руководитель продукта использует его для анализа эффективности продаж, управления ассортиментом и разработки стратегии[cite: 6]. [cite_start]Для CEO дашборд служит инструментом контроля на ежемесячных встречах в Zoom, где обсуждаются ключевые тенденции и планируются дальнейшие шаги[cite: 7].
